
# UBC - Universal Bet Converter

A backend project for converting betting slips
between supported bookmakers.

## Supported bookmakers

- MelBet
- 1xBet

## Technologies

- Node.js
- Express
- JavaScript

## Installation

npm install

## Start server

npm start

## API endpoints

GET /api/health

POST /api/convert

## Development status

Backend foundation created.

Slip decoder and genuine bookmaker conversion
integration are still under development.
